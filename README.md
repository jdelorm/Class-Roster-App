Title: Student Roster Management App

Purpose: To manage a class roster by adding, removing, and printing student information, while categorizing students based on their degree program (Network, Security, or Software). 
The program validates email addresses, calculates the average days in course for each student, and prints information based on degree program.

Author: John DeLorme

Contact: jdelorm@wgu.edu

Version: 1.5

Date: 9/18/2024

IDE: Visual Studio 2024

C++ Version: C++17

Libraries:

1. <iomanip>
2. <iostream>
3. <sstream>
4. <string>

How to Get Program to Run:

1. Install the latest edition of Visual Studio.
2. Open Visual Studio and select "Get from Version Control" from the main screen.
3. Paste this URL into the "Repository URL" field: https://github.com/jdelorm/Class-Roster-App
4. Choose the directory where you'd like to save the project and click "Clone".
5. Open the cloned project in Visual Studio.
6. Build the solution by selecting "Build Solution" from the "Build" menu.
7. Once the program is compiled successfully, select "Start Debugging" or press F5 to run the program.
8. The program will execute and print the class roster, invalid emails, average days in course by student ID, and students in the SOFTWARE degree program.
